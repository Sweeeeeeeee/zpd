Funkcija f : R → R definēta visiem reāliem skaitļiem un pieņem reālas vērtības. Visiem
reāliem skaitļiem a un b izpildās
2 f (a ) ≤ f (b) + f (2a − b).
Vai tiesa, ka visiem reāliem a, b un c izpildās
3 f (a ) ≤ f (b) + f (c) + f (3a − b − c) ?
