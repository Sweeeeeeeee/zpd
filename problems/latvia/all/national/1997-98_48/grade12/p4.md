Pieņemsim, ka n – naturāls skaitlis. Funkcijas f ( x, y ) argumenti un vērtības ir
naturāli skaitļi, kas nepārsniedz n. Dots, ka katriem naturāliem x un y, kas nepārsniedz
n, pastāv vienādības

f ( f ( x, y ), y ) = x un f ( x, f ( x, y )) = y .

a) pierādīt, ka visiem naturāliem x un y, kas nepārsniedz n, pastāv vienādība
f ( x, y ) = f ( y , x ) ;
b) kādiem naturāliem n šāda funkcija f eksistē ?
