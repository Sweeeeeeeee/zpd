Funkcija f (n ) definēta visām veselām n vērtībām, un tās vērtības ir veseli
skaitļi. Zināms arī, ka
a) visiem veseliem m un n pastāv vienādība
f (m + n ) + f (m − n ) = 2 f (m ) ⋅ f (n ) ,
b) funkcija f (n ) ir ierobežota.

Atrast visas šādas funkcijas.
