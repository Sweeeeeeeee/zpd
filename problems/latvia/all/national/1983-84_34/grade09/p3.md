Konstruēt kaut vienu funkciju f ( x ) , kas vienlaikus apmierina šādas trīs īpašības:
a)

f ( x ) definēta visām x vērtībām;

b) eksistē divi tādi skaitļi a un b, ka f (a ) − f (b ) ≠ a − b ;
c) ja x – y ir racionāls skaitlis, tad f ( x ) − f ( y ) = x − y .
