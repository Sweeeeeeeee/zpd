Ilīrijā tiek lietota algebriska operācija, kas tiek apzīmēta ar aplīti o . Šī
operācija tiek pielietota visiem skaitļiem, un tās rezultāts arī ir skaitlis. Ir zināms, ka
visiem x un y pastāv vienādības
1) x o ( x o y ) = y ,
2) ( x o y ) o y = x .

a) Pierādiet, ka katriem diviem skaitļiem x un y pastāv vienādība
xo y = yo x.
b) Vai var pierādīt, ka katriem trim skaitļiem a, b un c pastāv vienādība

(a o b) o c = a o (b o c ) ?
