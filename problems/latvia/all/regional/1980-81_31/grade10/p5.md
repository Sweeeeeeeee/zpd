Funkcija f ( x ) definēta visiem reāliem x. Zināms, ka katram x pastāv
nevienādība f ( x ) ≤ x , un zināms, ka katriem diviem skaitļiem x un y pastāv
nevienādība

f (x + y ) ≤ f (x ) + f ( y ) .
Pierādīt, ka katram x pastāv vienādība
f (x ) = x .
