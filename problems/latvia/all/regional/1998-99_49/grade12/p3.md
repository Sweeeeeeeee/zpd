Funkcija f (t ) definēta visiem reāliem t, pieņem reālas vērtības un visiem x un y
apmierina vienādību
f (x + y ) + f (x − y ) = f (x ) ⋅ f ( y ) .
Turklāt zināms, ka f (0) ≠ 0 .
Pierādīt, ka
a) visiem x pastāv vienādība f ( x ) = f (− x ) ,
b) ja eksistē tāds skaitlis b, ka

f ( x + 4b ) = f ( x ) .

f (b ) = 0 , tad visiem x pastāv vienādība
