Skaitļu virkni, kurā ir N elementi, sauksim par N mazāko naturālo skaitļu permutāciju, ja tajā
atrodami visi naturālie skaitļi no 1 līdz N.
Zināms, ka virkne {ai } ir n (n > 3) mazāko naturālo skaitļu permutācija.
Virknes {bi } (1 ≤ i ≤ n − 1) elementus aprēķina pēc formulas bi = |ai+1 − ai |.
Virknes {ci } (1 ≤ i ≤ n − 2) elementus aprēķina pēc formulas ci = |bi+1 − bi |.
Pierādīt, ka {bi } un {ci } vienlaikus abas nevar būt attiecīgi n − 1 un n − 2 mazāko naturālo
skaitļu permutācijas!
