Ir zināms, ka f ( x ) un g ( x ) - kvadrāttrinomi, pie tam gan 2f ( x ) + g ( x ) , gan
f ( x ) − g ( x ) ir tāds kvadrāttrinoms, kuram ir tikai viena sakne (jeb, citādi sakot,
abas saknes ir vienādas). Dots arī, ka kvadrāttrinomam f ( x ) ir divas dažādas
saknes. Pierādīt, ka kvadrāttrinomam g ( x ) sakņu nav.
