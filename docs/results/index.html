When does one more point help?

A geometry solver starts with the points in a problem. When deduction stalls, a midpoint, a projection or a model-generated construction can give it another way to prove the goal.

For example, in L058-9 the mini_long model placed F on AB, equidistant from A and B. Since C is also equidistant from A and B, CF lies on the perpendicular bisector. The three parallel lines AE, FC and BD now cut equal intervals on both transversals, giving EC = CD.

Predicting the first auxiliary point

Each model proposed four constructions. A strict match requires the reference point name and the same predicates with each argument in its original position. Predicate order can vary. This score can miss equivalent constructions. Only a proof run establishes whether a proposal solves the problem.
